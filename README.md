# One Trillion Dollars
One Trillion Dollars is a 3D adventure puzzle platformer made for Down2Jam 4. The theme was Scaling.

### Goals
I really wanted to explore new systems and mechanics this time around, and I wanted to continue learning and improving my 3D skills. I always thought the climbing mechanics in PEAK were neat, so I sort of emulated that a little bit in my own way. It took a bit of figuring out, but it was a great opportunity to learn about more 3D physics, especially when it comes to a physics-based character.
